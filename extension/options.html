JobApp Agent

Runs browser work for your server using this browser's own sessions.

The address you open the app at, including https://
The AGENT_TOKEN value from your server's .env — not your login password.
Lets this extension open aggregator redirect pages (Adzuna, Jooble, Indeed) to find the employer's real apply link — the step your server gets blocked on. Requires permission to read any site, requested when you tick it, and revocable here at any time. Requests are sent without cookies.
When a site refuses a background request — Jooble and Indeed both do — this reopens it as a real page load in a minimized window, reads where it landed, and closes it. One at a time. Untick to let those tasks simply fail instead.
While you browse a job site normally, harvesting reads the job data the page already received and sends it to your server — full descriptions and salary bands the public APIs never return, at no extra requests. Each site below is a separate permission, asked for when you tick it and given back when you untick it: "read every job board you visit" is a different thing to agree to than "read LinkedIn", so they are not bundled. Nothing is sent from any site you have not ticked.
Adds a small panel to LinkedIn and the ATS boards (Greenhouse, Lever, Ashby, Workday, Workable, SmartRecruiters, Recruitee) showing this job's match score, whether you already applied, and what the posting said about sponsorship — plus a button to save it and write documents.
